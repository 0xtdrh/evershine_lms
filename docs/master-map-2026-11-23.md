## 5) الموقع الرئيسي (x01) — التظبيط
**اللي اتبنى (12/11):** الصفحة الجديدة على `/new-home` (مخفية، للأدمن) + صفحات التعليم والحلول والمنتجات والإنجازات والميديا والشراكات وعن TechNova والتأكد من الشهادة + شاشة «الموقع» (إظهار/إخفاء وتعديل نصوص) + الفورمات + إحصاءات الزوار.
**الصفحة الحالية (`app/page.tsx`) لسه شغّالة وملمسناهاش — قرارك:** نبدّل لما الجديدة تجهز.

**شغل التظبيط المقترح:**
1. مراجعة كاملة في المتصفح (موبايل + ديسكتوب، عربي + إنجليزي، فاتح/داكن): كل صفحة، كل زرار، كل فورم، سرعة التحميل، الصور.
2. محتوى حقيقي منك: قايمة المحتوى، فيديو الهيرو (سكريبتك)، صور وفيديوهات حقيقية — بدون عملاء أو أرقام وهمية.
3. الفورمات توصّل للسيستم (طلبات الموقع) + «احجز حصة تجريبية» و«إزاي ابني بيتعلم» مستنيين p12.
4. SEO: عناوين ووصف وsitemap وOpen Graph وGoogle (مؤجل في القرار الأول، يترفع).
5. الفعاليات والحملات (صفحات مخفية + QR) ومربعات المجالات (مؤجلة).
6. التبديل: `/new-home` تبقى الرئيسية بعد موافقتك، + الدومين الحقيقي + الاستضافة.
7. فحص: ما نلمسش الصفحة الحالية قبل موافقتك؛ منهج «Nova Signature» لسه مسودة — مننشرش تفاصيله من غير ما أسألك.

## ✅ المتبقي مرتّب (تحديث 23/11 مساءً)

**خلص من المرحلة 1:** مراجعة الأمان (3 أجزاء) · C05/D08 (الحجز يرجع محجوز بعد إلغاء الإيصال + الكود يرجع) · C15 (نافذة تأكيد واحدة في 48 شاشة) · الدفعة الصغيرة (عربي افتراضي، «موافق على الكل»، بحث عربي، قفل المقاعد).

### المرحلة 1 — تقفيل الأساس (الباقي)
1. حضور المدرب على الموبايل: الشاشة بتتحرك بعد أول ضغطة، اختيار الجروب تلقائي، أزرار ح/غ/م/ب أكبر.
2. الجواز: تجربة P01–P04 في المتصفح → تصميم الأختام (شكل/ألوان/حركة، موبايل أولًا).
3. تشغيل وطوارئ: تنبيه للسوبر أدمن عند الأخطاء، تحذير قبل الخروج التلقائي، فحص Data Health «مكان مالوش حد يوافق على إلغاء الدفعات / الاسترداد».
4. صغيرة من التجربة: صياغة «رقية هيكمّل» (مذكر/مؤنث في رسالة التجديد).
4-ب. **فحص شامل لكل عمليات الفلوس (المالك 28/11 — أولوية عالية):** مراجعة كل طريق فلوس (تسجيل دفعة، أونلاين، إثبات تحويل، محفظة وشحن وسحب، خصومات وأكواد، استرداد، إلغاء إيصال، تحويل طالب بين جروبات، رسوم إضافية، خزنة وتحويلات وجرد، قفل الشهر، أجر المدرب، كشوف الشركاء) + سكربت «ميزان» يتأكد إن الأرقام بتقفل على بعض في كل حالة (المدفوع = الفواتير = المحفظة = الخزنة = التقارير) + سيناريوهات حافة (دفعتين في نفس اللحظة، إلغاء بعد قفل الشهر، استرداد بعد تحويل…) تتحط في e2e. أي فرق = يتصلّح قبل أي حاجة تانية.

### المرحلة 2 — اللي ولي الأمر بيشوفه
5. الصفحة الرئيسية لولي الأمر للموبايل (قسم 7 في الخطة) — **مستني موافقتك على الشكل**.
6. «عايز أوقف ابني/بنتي» (طلب للموظف).
7. تنظيم الشاشات دفعة 5 + الحركة والـ skeleton (دفعة 4).
8. X01 دمج العيل المكررة · X02 ولي أمر تاني من البوابة · X13 رؤية كل ولي أمر لأبنائه عند الانفصال.
9. دورة الجروب F14/F15: نقل الشهر أوتوماتيك، «ادمج دلوقتي»، صفحة «الجروبات اللي مش كاملة»، صفحة «قواعدي».
9-ج. **مدرسة الطالب (المالك 28/11):** قايمة مدارس (اسم + منطقة + نوع حكومي/خاص/دولي) يديرها الموظف، والطالب/ولي الأمر يختار مدرسته وقت التسجيل وفي البروفايل (أو «مش موجودة» → الموظف يضيفها). يتعمل **قبل البيانات الحقيقية** علشان الداتا تتجمع من أول يوم. إحصائيات: كام طالب من كل مدرسة، لكل فرع/تراك، النمو، المدارس اللي مفيش منها حد (للتسويق والشراكات). مرتبط بالاستيراد/التصدير والتقارير.
9-د. **مهام السكرتيرة (المالك وافق 28/11 «مع تطوير»):** قايمة مهام يومية تلقائية (افتح الخزنة، اتصالات المتابعة، تأكيد حصص بكرة، تحصيل المتأخرين، طلبات اليوم) فوق «شغلك النهارده» + مهام يضيفها المدير (لشخص أو لكل سكرتارية فرع، بمعاد، متكررة يومي/أسبوعي) ويتابع اتعملت ولا لأ + تقرير إنجاز لكل موظف + تنبيه لما مهمة تتأخر. التطوير: قوالب مهام لكل دور (مش السكرتيرة بس)، ونقاط/تقييم أداء الموظف.
9-هـ. **التسجيل الكامل + الفورمات + CRM (المالك 28/11 — قبل الإطلاق، بيتصمم الأول ويتناقش):** ده «باب الدخول» للطلاب الجداد، فيتعمل قبل التشغيل مع الموقع (يحل محل p12):
   - **رحلة التسجيل كاملة:** مهتم (من الموقع / إعلان / واتساب / زيارة / شريك / ترشيح) → متابعة → حصة تجريبية أو اختبار تحديد مستوى → اقتراح الكورس والجروب → حجز → دفع → دخول الجروب → ترحيب وأول أسبوع. كل خطوة ليها حالة ومسؤول وتذكير، والعيلة تشوف هي فين.
   - **فورم بيلدر من السيستم:** الموظف يعمل فورم (تسجيل، حصة تجريبية، فعالية، استبيان، طلب منحة) من غير كود: الحقول، الإجباري، الاختيارات، الشروط، اللغة، لينك/QR، وكل رد يدخل السيستم (عميل محتمل / طالب / حجز). نسخة أولى قبل الإطلاق للتسجيل والحصة التجريبية، والباقي بعدين.
   - **CRM:** كل عميل محتمل بمصدره وحالته (جديد → اتكلمنا → حصة تجريبية → اتسجل / مش مهتم + السبب)، مسؤول ومعاد متابعة، سجل التواصل (موجود)، قوالب رسايل واتساب، تقارير التحويل (من كل مصدر/حملة/موظف كام اتسجل)، وتنبيهات «مهتم ماحدش كلمه». نسخة أولى قبل الإطلاق (المراحل + المتابعة + المصدر)، والتطوير (حملات، تقييم العميل، أتمتة) أول 3 شهور.
   - مرتبط بالموجود: حساب العيلة، الحجز، الأكواد، الإحالات، سجل التواصل، المتابعات، طلبات الموقع، «شغلك النهارده».
9-ب. **كورس مسجّل «مفتوح لكل الطلاب» (المالك 24/11 — قبل الإطلاق):** خيار على الكورس المسجّل (مجاني) يخلّيه يظهر لكل طالب مسجّل عندنا في «دروسي» من غير حجز، مع تحديد اختياري بالفرع / التراك / السن. الطالب يتسجّل فيه تلقائي أول ما يفتحه (مفيش فواتير)، نفس حماية الفيديو (علامة مائية + حد الأجهزة)، ويدخل في التقارير (مين اتفرج ووصل لفين). ينفع كهدية / كورس تعريفي / تسويق لكورس مدفوع. مرتبط بـ: الكورسات المسجلة (M4)، دقائق المشاهدة، «شغلك النهارده» والتقارير (one system).
